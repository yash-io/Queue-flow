# Queue-flow – Q&A Blog Platform

**Queue-flow** is a modern Q&A blog-style platform where anyone can post text-based questions and answers, reply to others, and engage in anonymous chat. Users can also create and customize their profile page. Built with **React**, **Vite**, **Firebase**, **TailwindCSS**, and various Node.js libraries, Queue-flow offers a seamless and interactive community experience.

## Features

- **Post Q&A:** Users can ask questions and post answers in a blog-style format.
- **Replies:** Respond directly to questions or answers, supporting threaded discussions.
- **Anonymous Chat:** Engage in private, anonymous conversations with other users.
- **Profile Page:** Each user has a customizable profile page.
- **Modern UI:** Responsive and fast interface powered by React, Vite, and TailwindCSS.
- **Real-time Updates:** Instant posting and chat via Firebase backend.

## Getting Started

### Prerequisites

- Node.js and npm
- Firebase account & project

### Installation

1. **Clone the repository:**
    ```sh
    git clone https://github.com/yash-io/Queue-flow.git
    cd queue-flow
    ```

2. **Install dependencies:**
    ```sh
    npm install
    ```

3. **Configure Firebase:**
    - Create a Firebase project.
    - Set up Firestore, Realtime Database, and Authentication.
    - Add your Firebase config to a `.env` file or as required by your codebase.

4. **Start the development server:**
    ```sh
    npm run dev
    ```

5. **Visit** [http://localhost:5173](http://localhost:5173) (default Vite port) to use Queue-flow locally.

## Usage

- **Sign up / Log in:** Create an account or log in to start posting.
- **Ask Questions:** Post your questions for the community.
- **Post Answers:** Reply to questions or other answers.
- **Anonymous Chat:** Start or join chat sessions without revealing your identity.
- **Edit Profile:** Customize your profile page for a personalized experience.
